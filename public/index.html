Locus · Welcome

An AI agent that runs in your browser.

It chats, reads the web and works in your tabs for you. The model runs on your graphics card and the chat is kept in this browser, so what you type is not sent to any AI service.

  • Checking your browser…

Setup downloads this page from Cloudflare Pages, the model from Hugging Face and the ONNX Runtime from jsDelivr, and each of them sees your IP address. After that, the only requests are the pages and searches the agent makes for you.

Step 1 of 2

Add the browser extension

On its own the agent can tell the time and your location, describe your device, send notifications and copy text. With the Locus Bridge extension it can also list, open and read your tabs, fetch pages, search the web, and click and type on pages for you.

Before you install it: the extension lets this page control any tab through Chrome's debugging protocol, including sites you are signed in to. Text on a web page can mislead the agent, so watch what it does on sites that matter, and remove the extension when you don't need it. While the agent works in a tab, Chrome shows a bar saying the extension started debugging the browser.

  1. Download the extension and unzip it.
  2. Open chrome://extensions in a new tab (in Edge, edge://extensions).
  3. Turn on Developer mode in the top right corner.
  4. Click Load unpacked and pick the extension folder from the zip.

Waiting for the extension…

The extension runs only a fixed set of commands, only for this site and localhost. Its code is in the extension folder of the repository. You can add it later; this page finds it when you reload.

Step 2 of 2

Download the model

The agent thinks with Qwen3.5-4B, an open language model. It downloads once, straight from Hugging Face, and stays in this browser's storage, so later visits start without downloading.
